# P10: Portfolio header and footer with advanced Flexbox

Use Flexbox to align the portfolio title, navigation and footer information.

## Aim
Practise `justify-content`, `align-items`, `gap` and `flex-wrap`.

## Files
- `index.html` contains a header, main content and footer.
- `style.css` uses Flexbox to align the header and footer items.

## How to run
Open `index.html` in a browser and resize the window to see the items wrap.

## What I learned
Flexbox can align items and distribute available space. Wrapping helps the layout on narrow screens.
