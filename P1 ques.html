Project folder and terminal navigation

Create a project folder and use terminal commands to move through it and check its contents.

Steps

  1. Open Terminal.
  2. Create a folder for the portfolio.
  3. Move into that folder.
  4. Create folders for CSS and images.
  5. Create the main HTML file and list the files.

Commands

mkdir my-portfolio
cd my-portfolio
mkdir css images
touch index.html
pwd
ls

What the commands do

  • mkdir creates a folder.
  • cd changes the current directory.
  • touch creates an empty file.
  • pwd shows the current folder path.
  • ls lists the files and folders.
