Newspaper-style three-column layout with CSS Grid

Create a newspaper-style layout with a wider main story and two smaller columns using CSS Grid.

HTML example

<main class="news-layout">
  <article class="main-story">
    <h2>Main story</h2>
    <p>The most important news goes here.</p>
  </article>
  <article><h2>News two</h2></article>
  <article><h2>News three</h2></article>
</main>

CSS code

.news-layout {
  display: grid;
  grid-template-columns: 2fr 1fr 1fr;
  gap: 20px;
}

.news-layout article {
  padding: 20px;
  background: #eee9df;
}

@media (max-width: 700px) {
  .news-layout {
    grid-template-columns: 1fr;
  }
}

Explanation

The 2fr 1fr 1fr values give the first column twice the space of each other column. The media query changes the layout to one column on narrow screens.
