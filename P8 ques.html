Sticky navbar and card overlay using CSS positioning

Use sticky positioning to keep the navigation at the top and absolute positioning to place a label over a card.

HTML example

<header class="navbar">My Portfolio</header>

<article class="project-card">
  <div class="project-image"></div>
  <span class="project-label">Featured project</span>
  <h2>My first project</h2>
</article>

CSS code

.navbar {
  position: sticky;
  top: 0;
  z-index: 10;
  padding: 16px;
  background: white;
}

.project-card {
  position: relative;
  padding: 20px;
  min-height: 220px;
  background: #e9e5dc;
}

.project-label {
  position: absolute;
  left: 20px;
  bottom: 20px;
  padding: 6px 10px;
  background: #202b36;
  color: white;
}

Explanation

position: sticky keeps the navbar visible after it reaches the top while scrolling. The card uses position: relative so the absolutely positioned label is placed relative to that card.
