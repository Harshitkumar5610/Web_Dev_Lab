Design tokens and typography system in CSS

Set up reusable CSS variables for colours, spacing and fonts, then use them throughout the page.

CSS code

:root {
  --color-text: #202b36;
  --color-background: #f5f3ee;
  --color-accent: #d46b4e;
  --space-small: 8px;
  --space-medium: 16px;
  --space-large: 32px;
  --font-body: Arial, sans-serif;
  --font-heading: Georgia, serif;
}

body {
  color: var(--color-text);
  background: var(--color-background);
  font-family: var(--font-body);
}

h1, h2, h3 {
  font-family: var(--font-heading);
}

.card {
  padding: var(--space-medium);
  margin-bottom: var(--space-large);
  border-top: 3px solid var(--color-accent);
}

Explanation

CSS custom properties are defined inside :root and can be reused with var(). This keeps the design consistent and makes later changes easier.
