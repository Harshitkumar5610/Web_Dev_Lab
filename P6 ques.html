Full portfolio page structure in semantic HTML

Create the main structure of a portfolio website using semantic sections and navigation links.

HTML structure

<header>
  <h1>My Portfolio</h1>
  <nav aria-label="Main navigation">
    <a href="#about">About</a>
    <a href="#projects">Projects</a>
    <a href="#contact">Contact</a>
  </nav>
</header>
<main>
  <section id="about">
    <h2>About Me</h2>
    <p>A short introduction about me.</p>
  </section>
  <section id="projects">
    <h2>My Projects</h2>
    <article>
      <h3>Project One</h3>
      <p>A short project description.</p>
    </article>
  </section>
  <section id="contact">
    <h2>Contact</h2>
    <p>Email: hello@example.com</p>
  </section>
</main>
<footer>Copyright 2026</footer>

Explanation

The navigation links point to section IDs. The article element groups one project, while the main element contains the page's main content.
