# P4: GitHub README and version tags

Write a README to explain the project and add a version tag in Git.

## Example README content
```markdown
# My Portfolio

This is my personal portfolio website.

## Sections
- About me
- My projects
- Contact

## Built with
- HTML
- CSS

## How to open
Open index.html in a browser.
```

## Commands to create a version tag
```bash
git add README.md
git commit -m "Add project README"
git tag -a v1.0 -m "First portfolio version"
git push origin main
git push origin v1.0
```

## What I learned
A README explains a project to other people. A Git tag marks a particular commit as a version.
