# P7: Design tokens and typography system in CSS

Use CSS custom properties for reusable colours, spacing and font settings.

## Aim
Create a small set of design tokens and use them in CSS.

## Main concepts
- `:root` stores custom properties.
- Variables are written with names beginning with `--`.
- `var()` uses a custom property.
- Typography settings keep headings and body text consistent.

## Files
- `index.html` shows sample text and cards.
- `style.css` defines and uses the design tokens.

## How to run
Open `index.html` in a browser. Change a colour or spacing value in `style.css` and refresh the page.

## What I learned
CSS variables make it easier to update the same design value in multiple places.


## Files in this practical
- [index.html](./index.html) — HTML structure and example.
- [style.css](./style.css) — external CSS used by the HTML page.

## How to view
Open `index.html` in a browser. The page loads its design from `style.css`.
