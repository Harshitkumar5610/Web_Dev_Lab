GitHub README and version tags

Write a README file to explain the project and create a version tag for a finished version.

Example README.md

# My Portfolio

This is my personal portfolio website.

## Sections
- About me
- My projects
- Contact information

## Built with
- HTML
- CSS
- JavaScript

## Running the project
Open index.html in a web browser.

Create and push a version tag

git add README.md
git commit -m "Add project README"
git tag -a v1.0 -m "First portfolio version"
git push origin main
git push origin v1.0

The README describes the project. The v1.0 tag marks a particular commit as a version.
