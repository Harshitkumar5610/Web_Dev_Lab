Responsive navbar and card grid using Flexbox

Use Flexbox to arrange navigation links and project cards, allowing them to wrap when the screen becomes narrow.

HTML example

<nav class="nav-links">
  <a href="#home">Home</a>
  <a href="#about">About</a>
  <a href="#work">Work</a>
  <a href="#contact">Contact</a>
</nav>

<div class="cards">
  <article class="card">Project 1</article>
  <article class="card">Project 2</article>
  <article class="card">Project 3</article>
</div>

CSS code

.nav-links {
  display: flex;
  flex-wrap: wrap;
  gap: 16px;
}

.cards {
  display: flex;
  flex-wrap: wrap;
  gap: 16px;
}

.card {
  flex: 1 1 220px;
  padding: 24px;
  background: #eee9df;
  border-radius: 10px;
}

Explanation

Flexbox arranges items in a row by default. flex-wrap: wrap lets them move onto another line when there is not enough space. The card basis helps cards keep a useful minimum width.
