Portfolio header and footer with advanced Flexbox

Arrange the portfolio title and navigation in the header, and align footer details using Flexbox.

HTML example

<header class="site-header">
  <strong>My Portfolio</strong>
  <nav>About · Work · Contact</nav>
</header>

<footer class="site-footer">
  <span>Made by me</span>
  <span>Back to top ↑</span>
</footer>

CSS code

.site-header, .site-footer {
  display: flex;
  align-items: center;
  justify-content: space-between;
  flex-wrap: wrap;
  gap: 16px;
  padding: 20px;
}

.site-header {
  background: #e9e5dc;
}

.site-footer {
  border-top: 1px solid #ddd5c9;
}

Explanation

justify-content: space-between places space between the items, align-items: center aligns them across the cross axis, and flex-wrap allows a second line on smaller screens.
