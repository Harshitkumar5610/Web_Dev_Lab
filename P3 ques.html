Feature-branch Git workflow

Create a separate branch for a new feature, make a change, commit it and push the branch to GitHub.

Commands

git switch -c feature/about-section

# Make changes to your files
git status
git add .
git commit -m "Add about section"
git push -u origin feature/about-section

Merge the feature

Open the repository on GitHub and create a pull request from feature/about-section into main. Review the changes and merge the pull request when they are ready.

This workflow keeps unfinished work separate from the main version of the project.
