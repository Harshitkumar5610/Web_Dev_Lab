# Web Development Lab Practicals

My practical work for **Programming for Web Development - I**, covering P1 to P13.

## Practicals

- [P1](./P1/) — Project folder and terminal navigation
- [P2](./P2/) — Portfolio repo with an initial commit
- [P3](./P3/) — Feature-branch Git workflow
- [P4](./P4/) — GitHub README and version tags
- [P5](./P5/) — Semantic bio page
- [P6](./P6/) — Full portfolio page structure in semantic HTML
- [P7](./P7/) — Design tokens and typography system in CSS
- [P8](./P8/) — Sticky navbar and card overlay using CSS positioning
- [P9](./P9/) — Responsive navbar and card grid using Flexbox
- [P10](./P10/) — Portfolio header and footer with advanced Flexbox
- [P11](./P11/) — Newspaper-style three-column layout with CSS Grid
- [P12](./P12/) — Portfolio projects grid with advanced CSS Grid
- [P13](./P13/) — Choosing between Flexbox and Grid for a shared layout

## Folder structure

Each practical has its own folder and its own `README.md`.

- **P1–P4:** README files with the terminal commands, Git steps and explanations.
- **P5–P13:** README files, an `index.html` example and a separate `style.css` file.

## How to use

1. Open this repository in Visual Studio Code.
2. Open the practical folder you want to study.
3. Read its `README.md`.
4. For P5–P13, open `index.html` in a browser to view the example.
5. Make your own changes and practise the code.

- HTML
