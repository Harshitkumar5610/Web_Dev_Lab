# P5: Semantic bio page

Build a short personal bio page using semantic HTML elements.

## Aim
Create a simple page with a heading, an introduction and interests. Use semantic elements such as `header`, `main`, `section` and `footer`.

## Files
- `index.html` contains the page content.
- `style.css` contains the page design.

## How to run
Open `index.html` in a browser. Edit the sample introduction and interests to make the page your own.

## What I learned
Semantic tags describe the purpose of page content and make the structure easier to understand.


## Files in this practical
- [index.html](./index.html) — HTML structure and example.
- [style.css](./style.css) — external CSS used by the HTML page.

## How to view
Open `index.html` in a browser. The page loads its design from `style.css`.
