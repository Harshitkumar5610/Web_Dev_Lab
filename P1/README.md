# P1: Project folder and terminal navigation

Create a project folder and practise moving around it with terminal commands.

## Steps
1. Open the terminal.
2. Create a folder for the portfolio.
3. Move into the folder.
4. Create folders for CSS and images.
5. Create an empty HTML file and list the folder contents.

## Commands
```bash
mkdir my-portfolio
cd my-portfolio
mkdir css images
touch index.html
pwd
ls
```

## What I learned
- `mkdir` creates a folder.
- `cd` changes the current folder.
- `touch` creates a file.
- `pwd` shows the current location.
- `ls` lists files and folders.

## Expected result
A `my-portfolio` folder containing `css`, `images` and `index.html`.
