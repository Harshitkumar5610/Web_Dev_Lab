# P1: Project folder and terminal navigation

## Aim
Create a project folder, move into it using the terminal, and create the basic folders and HTML file.

## Commands used

```bash
mkdir my-portfolio
cd my-portfolio
mkdir css images
touch index.html
pwd
ls
```

## What the commands do
- `mkdir my-portfolio` creates the main project folder.
- `cd my-portfolio` opens that folder in the terminal.
- `mkdir css images` creates folders for CSS files and images.
- `touch index.html` creates an empty HTML file.
- `pwd` shows the current folder location.
- `ls` lists the files and folders.

## Expected project structure

```text
my-portfolio/
├── css/
├── images/
└── index.html
```

## Result
The portfolio project folder and its basic structure were created using terminal commands.
