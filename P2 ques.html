Portfolio repo with an initial commit

Turn the portfolio folder into a Git repository and save its first version on GitHub.

Commands

cd my-portfolio
git init
git add .
git commit -m "Create portfolio starter"
git branch -M main
git remote add origin YOUR_REPOSITORY_URL
git push -u origin main

Replace YOUR_REPOSITORY_URL with the HTTPS URL of the GitHub repository you created.

Result

The folder is now tracked by Git. The first commit saves the current files, and the push sends that commit to the GitHub repository.
