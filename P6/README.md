# P6: Full portfolio page structure in semantic HTML

Create the structure of a portfolio with navigation, about, projects and contact sections.

## Aim
Build a basic portfolio page using semantic HTML.

## Page sections
- Header and navigation
- About me
- Projects
- Contact
- Footer

## Files
- `index.html` contains the portfolio sections.
- `style.css` styles the page.

## How to run
Open `index.html` in a browser and use the navigation links to move to each section.

## What I learned
Semantic HTML gives each part of a page a clear purpose. Section IDs allow navigation links to jump to the right place.


## Files in this practical
- [index.html](./index.html) — HTML structure and example.
- [style.css](./style.css) — external CSS used by the HTML page.

## How to view
Open `index.html` in a browser. The page loads its design from `style.css`.
