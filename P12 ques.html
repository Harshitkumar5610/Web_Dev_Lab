Portfolio projects grid with advanced CSS Grid

Display project cards in a grid that automatically adjusts the number of columns to fit the available width.

HTML example

<section class="project-grid">
  <article class="project-card">
    <h2>Project One</h2>
    <p>A short description of the project.</p>
  </article>
  <article class="project-card">
    <h2>Project Two</h2>
    <p>A short description of the project.</p>
  </article>
  <article class="project-card">
    <h2>Project Three</h2>
    <p>A short description of the project.</p>
  </article>
</section>

CSS code

.project-grid {
  display: grid;
  grid-template-columns:
    repeat(auto-fit, minmax(220px, 1fr));
  gap: 20px;
}

.project-card {
  padding: 24px;
  background: #eee9df;
  border-radius: 12px;
}

Explanation

repeat() creates repeated columns. auto-fit fits as many columns as possible, while minmax(220px, 1fr) keeps each card at least 220 pixels wide and lets it grow to share the space.
