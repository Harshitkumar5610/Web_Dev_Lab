# P11: Newspaper-style three-column layout with CSS Grid

Create a newspaper-style page with a large main story and two smaller story columns.

## Aim
Use CSS Grid to create a three-column layout.

## Main concepts
- `display: grid` turns an element into a grid container.
- `grid-template-columns` sets the column sizes.
- `fr` shares available space.
- A media query changes the layout on smaller screens.

## Files
- `index.html` contains three story articles.
- `style.css` defines the grid.

## How to run
Open `index.html` in a browser and resize the window.

## What I learned
Grid is useful when a page needs rows and columns together.
