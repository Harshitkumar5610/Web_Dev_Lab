# P9: Responsive navbar and card grid using Flexbox

Use Flexbox to arrange navigation links and cards so they can wrap on smaller screens.

## Aim
Practise `display: flex`, `gap`, `flex-wrap` and flexible card widths.

## Main concepts
- Flexbox arranges items along a row or column.
- `gap` adds space between items.
- `flex-wrap` lets items move to another line.
- A media query can adjust the layout for small screens.

## Files
- `index.html` contains navigation and project cards.
- `style.css` contains the Flexbox and responsive rules.

## How to run
Open `index.html` in a browser. Make the browser window narrower to see the layout change.

## What I learned
Flexbox helps arrange items while allowing them to fit different screen sizes.


## Files in this practical
- [index.html](./index.html) — HTML structure and example.
- [style.css](./style.css) — external CSS used by the HTML page.

## How to view
Open `index.html` in a browser. The page loads its design from `style.css`.
