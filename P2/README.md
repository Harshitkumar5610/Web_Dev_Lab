
# P2: Portfolio repo with an initial commit

Create a Git repository for the portfolio and save its first version.

## Steps
1. Open the portfolio folder in the terminal.
2. Start Git in the folder.
3. Add the files and make the first commit.
4. Create an empty GitHub repository.
5. Connect the local project to GitHub and push it


## Commands
```bash
git init
git add .
git commit -m "First portfolio commit"
git branch -M main
git remote add origin YOUR_REPOSITORY_URL
git push -u origin main
```

Replace `YOUR_REPOSITORY_URL` with the HTTPS URL of your own GitHub repository.

## What I learned
Git tracks changes in a project. A commit saves a version, and pushing sends the commits to GitHub.

## Expected result
The project files appear in the GitHub repository.
