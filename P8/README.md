# P8: Sticky navbar and card overlay using CSS positioning

Keep a navigation bar at the top while scrolling and position a label over a project card.

## Aim
Practise `position: sticky`, `position: relative` and `position: absolute`.

## Main concepts
- The navbar sticks to the top while scrolling.
- The card uses relative positioning as the reference.
- The label is positioned inside the card.

## Files
- `index.html` contains the navbar and project card.
- `style.css` contains all positioning rules.

## How to run
Open `index.html` in a browser and scroll down to test the sticky navbar.

## What I learned
Positioning properties control where elements appear on a page.


## Files in this practical
- [index.html](./index.html) — HTML structure and example.
- [style.css](./style.css) — external CSS used by the HTML page.

## How to view
Open `index.html` in a browser. The page loads its design from `style.css`.
