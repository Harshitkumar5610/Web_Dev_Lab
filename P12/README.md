# P12: Portfolio projects grid with advanced CSS Grid

Make a responsive project gallery using repeat(), minmax() and auto-fit.

## Aim
Create a project grid that adjusts its columns to the available width.

## Main concepts
- `repeat()` creates repeated columns.
- `minmax()` sets a minimum and maximum size.
- `auto-fit` fits as many columns as possible.
- `gap` adds space between cards.

## Files
- `index.html` contains the project cards.
- `style.css` contains the grid layout.

## How to run
Open `index.html` in a browser and change the window width.

## What I learned
CSS Grid can make a responsive card layout without writing a separate rule for every screen size.


## Files in this practical
- [index.html](./index.html) — HTML structure and example.
- [style.css](./style.css) — external CSS used by the HTML page.

## How to view
Open `index.html` in a browser. The page loads its design from `style.css`.
